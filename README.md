# 📰 News360 Rubika Bot

ربات خبر هوشمند با رابط گرافیکی — اخبار را از منابع خبری (RSS) جمع‌آوری می‌کند و
**فقط و فقط در کانال روبیکا** منتشر می‌کند.

> 💎 در این نسخه، تلگرام و بله به‌طور کامل حذف شده‌اند. تنها مقصد انتشار، کانال روبیکا است.
> (گوگل ترنسلیت یک شبکه اجتماعی نیست؛ فقط سرویس ترجمه اخبار خارجی است و باقی مانده.)

## ✨ امکانات

- 📥 جمع‌آوری خبر از ۶ منبع داخلی (ایرنا، ایسنا، مهر، فارس، خبرآنلاین، خبرگزاری جوان) و ۴ منبع خارجی (BBC، Reuters، CNN، الجزیره)
- 🧠 دو الگوریتم انتشار: **Smart Priority** (اولویت هوشمند) و **Source Rotation** (چرخش منبع)
- 🌐 ترجمه خودکار اخبار خارجی با Google Translate + پس‌پردازش سبک خبری
- 🚨 تشخیص خبر فوری و 🔥 تشخیص خبر وایرال
- 🔄 حذف اخبار تکراری و فیلتر استان‌ها
- 🖥 رابط گرافیکی Glassmorphism با مانیتورینگ کامل (وضعیت روبیکا، منابع RSS، آمار و ...)

## 🚀 راه‌اندازی

### ۱) نصب پیش‌نیازها

پایتون ۳.۹ به بالا (نسخه رسمی ویندوز شامل tkinter هست):

```bash
pip install -r requirements.txt
```

### ۲) ساخت ربات روبیکا

1. در پیام‌رسان **روبیکا**، ربات **BotFather** (بات‌فادر روبیکا) را پیدا کنید.
2. یک ربات جدید بسازید و **توکن** آن را دریافت کنید.
3. ربات را به کانال خود اضافه کرده و **ادمین** کنید (با دسترسی ارسال پیام).

### ۳) اجرای رابط گرافیکی

```bash
python run_bot_gui_advanced.py
```

سپس در برنامه:

1. در پنل سمت راست، بخش **▌ RUBIKA SETTINGS** را باز کنید.
2. **Bot Token** (توکن ربات) و **Channel ID** (آیدی کانال، مثل `@news360_24`) را وارد کنید.
3. دکمه **💾 SAVE SETTINGS** را بزنید (در فایل `rubika_config.json` ذخیره می‌شود).
4. دکمه **▶ START** را بزنید.

وضعیت اتصال روبیکا در بخش **PLATFORM STATUS** و نوار پایین پنجره نمایش داده می‌شود:
🟢 ONLINE یعنی ربات وصل است و اخبار فقط به کانال روبیکا ارسال می‌شوند.

### اجرای بدون رابط گرافیکی (اختیاری)

```bash
python bot.py
```

تنظیمات به ترتیب اولویت از این مسیرها خوانده می‌شود:

1. متغیرهای محیطی `RUBIKA_BOT_TOKEN` و `RUBIKA_CHANNEL_ID`
2. فایل `rubika_config.json` (ساخته‌شده توسط رابط گرافیکی)
3. مقادیر `DEFAULT_RUBIKA_BOT_TOKEN` و `DEFAULT_RUBIKA_CHANNEL_ID` در ابتدای `bot.py`

## ⚙️ نحوه ارسال به روبیکا

ارسال از طریق **API رسمی ربات روبیکا** انجام می‌شود:

```
https://botapi.rubika.ir/v3/{token}/{method}
```

- پیام متنی: `sendMessage`
- عکس/ویدیو: دانلود رسانه ← `requestSendFile` ← آپلود ← `sendFile`
- قالب پیام‌ها متن ساده است (روبیکا برخلاف تلگرام HTML پشتیبانی نمی‌کند).

## 🧪 تست‌ها

بدون نیاز به اینترنت یا توکن واقعی (API روبیکا به‌صورت محلی شبیه‌سازی می‌شود):

```bash
python tests/test_rubika_bot.py   # تست کلاینت روبیکا و جریان ارسال خبر
python tests/test_gui_smoke.py    # تست ساخت رابط گرافیکی و منطق دکمه‌ها
```

## 🔒 نکات امنیتی

- فایل `rubika_config.json` حاوی توکن است و در `.gitignore` قرار دارد؛ آن را منتشر نکنید.
- ⚠️ توکن ربات تلگرامِ نسخه قبلی به‌صورت عمومی در کد قرار داشت؛ اگر هنوز فعال است،
  حتماً از طریق BotFather تلگرام آن را **باطل (Revoke)** کنید.
