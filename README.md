# 📰 News360 Rubika Bot

ربات خبر هوشمند — اخبار را از منابع خبری (RSS) جمع‌آوری می‌کند و
**فقط و فقط در کانال روبیکا** منتشر می‌کند.

> ☁️ **اجرای ابری روی GitHub Actions**: ربات به‌صورت خودکار روی گیت‌هاب اجرا می‌شود
> و دیگر نیازی به روشن‌بودن سیستم شخصی شما نیست.
> 💎 تلگرام و بله به‌طور کامل حذف شده‌اند؛ تنها مقصد انتشار، کانال روبیکا است.
> 🇮🇷 فقط منابع خبری داخلی؛ منابع خارجی و سرویس ترجمه حذف شده‌اند.
> 🔗 پست‌ها بدون لینک خبر منتشر می‌شوند (فقط عنوان، خلاصه، منبع و آیدی کانال).

## ✨ امکانات

- 📥 جمع‌آوری خبر از ۶ منبع داخلی: ایرنا، ایسنا، مهر، فارس، خبرآنلاین، خبرگزاری جوان
- 🔁 الگوریتم انتشار: **Source Rotation** (چرخش منبع) — تنها الگوریتم انتشار (Smart Priority حذف شد)
- ✍️ سبک خبری روی **همه خبرها**: اعداد فارسی ۰-۹، نشانه‌گذاری صحیح «، ؛ ؟»، نیم‌فاصله استاندارد و پاک‌سازی متن
- 🚨 تشخیص دقیق خبر فوری: امتیازدهی وزنی عنوان/خلاصه + عبارت‌های قطعی + گارد تکذیب (شایعه/تکذیب هرگز فوری نمی‌شود)
- 🔥 تشخیص دقیق خبر وایرال: بازتاب یک رویداد در ≥۲ منبع دیگر، پنجره زمانی ۶ ساعته، گارد اعداد متفاوت (کاهش مثبت کاذب)
- 🔄 حذف اخبار تکراری + ذخیره وضعیت بین ری‌استارت‌ها (خبر تکراری بعد از هر نوبت ارسال نمی‌شود)
- 🖥 رابط گرافیکی اختیاری برای اجرای محلی/تنظیمات

## ☁️ راه‌اندازی اجرای ابری (پیشنهادی — بدون نیاز به سیستم شخصی)

### ۱) ساخت ربات روبیکا

1. در پیام‌رسان **روبیکا**، ربات **BotFather** (بات‌فادر روبیکا) را پیدا کنید.
2. یک ربات جدید بسازید و **توکن** آن را دریافت کنید.
3. ربات را به کانال خود اضافه کرده و **ادمین** کنید (با دسترسی ارسال پیام).

### ۲) تعریف سکرت‌ها در گیت‌هاب

در مخزن گیت‌هاب به این مسیر بروید:

**Settings → Secrets and variables → Actions → New repository secret**

| نام سکرت | مقدار |
|---|---|
| `RUBIKA_BOT_TOKEN` | توکن ربات روبیکا |
| `RUBIKA_CHANNEL_ID` | آیدی کانال، مثل `@news360_24` |

🔒 توکن را هیچ‌جای دیگری (کد، چت، ایشو و ...) قرار ندهید؛ فقط در Secrets.

### ۳) فعال‌سازی اجرا

1. مطمئن شوید این ورک‌فلو روی برنچ **main** قرار دارد (schedule فقط روی برنچ پیش‌فرض اجرا می‌شود).
2. به تب **Actions** بروید → **Rubika News Bot** → **Run workflow**.
3. تمام! ربات به‌صورت زنجیره‌ای و دائمی اجرا می‌شود.

### نحوه کار اجرای ابری

- هر جاب گیت‌هاب حداکثر ۶ ساعت می‌تواند اجرا شود؛ ربات هر نوبت **~۵.۵ ساعت** کار می‌کند،
  وضعیت را در `state/bot_state.json` کامیت می‌کند و ورک‌فلو **خودش نوبت بعدی را شروع می‌کند**.
- یک **cron پشتیبان** (هر ۵ ساعت) هم وجود دارد تا اگر زنجیره قطع شد، ربات دوباره بالا بیاید.
- `concurrency` جلوی اجرای همزمان چند نوبت را می‌گیرد.
- وضعیت خبرهای ارسال‌شده بین نوبت‌ها حفظ می‌شود؛ خبر تکراری ارسال نمی‌شود.

### ⏸ توقف / ▶️ شروع دوباره

- **توقف موقت:** در **Settings → Secrets and variables → Actions → Variables** یک متغیر
  `BOT_ENABLED` با مقدار `false` بسازید و اجرای در حال انجام را در تب Actions **Cancel** کنید.
- **شروع دوباره:** مقدار `BOT_ENABLED` را `true` کنید (یا حذفش کنید) و **Run workflow** بزنید.
- **توقف کامل:** ورک‌فلو را از تب Actions → «...» → **Disable workflow** غیرفعال کنید.

### ⚠️ نکات مهم اجرای ابری

- **مخزن خصوصی (Private):** پلن رایگان گیت‌هاب فقط **۲۰۰۰ دقیقه در ماه** Actions دارد
  (~۳۳ ساعت). اجرای ۲۴/۷ حدود **۴۳٬۲۰ دقیقه در ماه** مصرف می‌کند!
  برای اجرای دائمی رایگان، مخزن را **Public** کنید (Actions برای مخزن عمومی رایگان و نامحدود است)
  یا پلن پولی تهیه کنید. سکرت‌ها در مخزن عمومی هم امن می‌مانند و فایل توکن محلی هم ignore شده است.
- زمان‌بندی cron گیت‌هاب ممکن است با تأخیر اجرا شود؛ زنجیره اجرای خودکار این فاصله را پر می‌کند.
- اگر مخزن ۶۰ روز هیچ فعالیتی نداشته باشد، گیت‌هاب schedule را غیرفعال می‌کند؛
  کامیت‌های خودکارِ وضعیت، مخزن را فعال نگه می‌دارند.
- در **Settings → Actions → General → Workflow permissions** گزینه
  **Read and write permissions** باید فعال باشد (برای کامیت وضعیت و شروع نوبت بعدی).
- ربات را همزمان روی سیستم شخصی و گیت‌هاب اجرا نکنید (ارسال تکراری می‌شود).

## 🖥 اجرای محلی با رابط گرافیکی (اختیاری)

```bash
pip install -r requirements.txt
python run_bot_gui_advanced.py
```

1. در پنل سمت راست، بخش **▌ RUBIKA SETTINGS** توکن و آیدی کانال را وارد کنید.
2. **💾 SAVE SETTINGS** و سپس **▶ START**.

وضعیت اتصال روبیکا در **PLATFORM STATUS** و نوار پایین پنجره نمایش داده می‌شود.

### اجرای بدون رابط گرافیکی (اختیاری)

```bash
python bot.py            # اجرای نامحدود
python run_bot_cloud.py  # اجرای زمان‌دار (پیش‌فرض ۳۳۰ دقیقه)
```

تنظیمات به ترتیب اولویت: متغیرهای محیطی `RUBIKA_BOT_TOKEN` و `RUBIKA_CHANNEL_ID` →
فایل `rubika_config.json` (ساخته‌شده توسط GUI) → مقادیر `DEFAULT_*` در ابتدای `bot.py`.

## ⚙️ نحوه ارسال به روبیکا

ارسال از طریق **API رسمی ربات روبیکا** انجام می‌شود:

```
https://botapi.rubika.ir/v3/{token}/{method}
```

- پیام متنی: `sendMessage`
- عکس/ویدیو: دانلود رسانه ← `requestSendFile` ← آپلود ← `sendFile`
- قالب پیام‌ها متن ساده است (روبیکا برخلاف تلگرام HTML پشتیبانی نمی‌کند).
